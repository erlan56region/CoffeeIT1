# CoffeeIT — Червяк Джим: Космическая кампания

Рекламный сайт о кофе на русском языке и расширенная браузерная игра про Червяка Джима. Проект работает без фреймворков, сборщиков и внешнего API.

## Запуск

```bash
python3 -m http.server 8080
```

- Сайт: `http://localhost:8080/`
- Игра: `http://localhost:8080/game/`
- Автономная версия: откройте `jim-game.html` как обычный файл — сетевой сервер не нужен.

## Игровая кампания

15 этапов, любой из которых можно выбрать прямо на стартовом экране:

1. Мусорный город — поиск рубильников.
2. Неоновая лаборатория — ключи и обучение.
3. Пещеры Астероид-X — лифты и три рубильника.
4. Кристальные сады — новое оружие и четыре терминала.
5. Космическая гонка — скутер с пропеллером, 10 км до финиша.
6. Ледяная комета — три ключа среди снарядов.
7. Плазменная фабрика — техногенные платформы и ловушки.
8. Воронья армада — пять шлюзов.
9. Лабиринт разума — три ключа и последовательность **2 → 4 → 1 → 3**.
10. Токсичная канализация — два ключа и пять клапанов.
11. Лавовый реактор — четыре охлаждающих ядра.
12. Часовой механизм — шесть шестерён-терминалов и особая последовательность.
13. Орбитальное кладбище — три сигнальных ключа и шесть маяков SOS.
14. Нулевое пространство — четыре фрагмента и пять порталов.
15. Цитадель Пси-Вороны — финальный босс и спасение принцессы.

В игре **24 типа противников и 8 друзей — 32 персонажа**. Поведение врагов включает патрулирование, пикирование, охоту, быстрые атаки, орбитальное движение, бомбардировку и огонь турелей. Друзья выдают лечение, жизни, патроны, очки, контрольные точки и оружие.

### Управление

| Действие | Клавиши |
| --- | --- |
| Выбор уровня на стартовом экране | ← / →, Enter или нажатие на карточку |
| Движение | A / D или ← / → |
| Прыжок и полёт на голове-вертолёте | W / ↑ / Пробел |
| Присесть | S / ↓ на земле |
| Прицеливание | Мышь, прицеливание на 360° |
| Огонь | ЛКМ / X / J; клавиши направления задают диагональ |
| Хлыст и активация терминалов | Z / K |
| Смена оружия | Q / E или 1 / 2 / 3 |
| Пауза | P / Escape |
| Подтверждение | Enter |

На сенсорных экранах доступны кнопки движения, приседания, прыжка, смены оружия, хлыста и стрельбы.

### Оружие

- **Плазма** — базовый автоматический бластер.
- **Триединый импульс** — три снаряда веером; открывает друг в Кристальных садах.
- **Рельсотрон** — медленный пробивающий выстрел; открывает друг в Пещерах Астероид-X.

Выстрелы начинаются у видимого кончика пистолета с учётом текущего кадра, поворота и отдачи. Жизни показаны иконками лица Джима из того же SNES-листа, что и игровые анимации.

## Анимация
Персонажи анимируются «скелетно» (cut-out): спрайты порезаны на части (голова, торс, руки, бёдра, голени, крылья…),
каждая часть вращается вокруг своего сустава.
- **Джим:** дыхание в покое, цикл бега (шаги, сгиб коленей, мах руками, наклон корпуса, пыль из-под ботинок),
  торможение-занос, разворот, толчок/прыжок/падение с размахиванием руками, приседание при приземлении,
  голова-вертолёт, отдача бластера со вспышкой, голова-хлыст на длинной шее, отброс при уроне, смерть с кувырком.
- **Вороны:** взмахи крыльев, пикирование со сложенными крыльями, падение кувырком с перьями.
- **Принцесса:** машет рукой, юбка колышется волной, подпрыгивает.
- **Ощущения:** хит-стоп при ударе, камера с упреждением, тень под Джимом.


## Структура

- `index.html`, `style.css`, `script.js` — рекламный сайт.
- `game/index.html` — контейнер игры и сенсорное управление.
- `game/game.js` — игровой цикл, физика, стрельба, отрисовка, звук и гонка.
- `game/campaign.js` — 10 этапов, генератор платформ, противники, друзья и головоломки.
- `game/assets/` — локальные изображения и спрайты.
- `art/source/` — сохранённый исходный SNES-лист.
- `art/build_animations.py` — воспроизводимая вырезка и очистка анимаций.
- `ART_SOURCES.md` — происхождение графики и правовая оговорка.
- `game/build_standalone.py` — встраивает скрипты и изображения в `jim-game.html`.

## Проверка и пересборка

```bash
node --check game/campaign.js
node --check game/game.js
node game/test_smoke.js
python3 game/build_standalone.py
```

Для повторной вырезки исходных кадров нужны Python, Pillow и NumPy:

```bash
python3 art/build_animations.py
```

Автономная HTML-версия уже собрана. Весь звук синтезируется Web Audio API после первого пользовательского действия; аудиофайлы не загружаются.
