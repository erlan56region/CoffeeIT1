# Червяк Джим — Космическое спасение (2D)

2D-платформер в стиле аниме/мультфильма на чистом HTML5 Canvas + JavaScript (без зависимостей).
Джим в космическом скафандре прорывается через астероиды, воюет с космическими воронами,
запускает коров и сражается с боссом **Пси-Вороной**, чтобы спасти Принцессу Как-Её-Там.

## Запуск

**Самый простой способ:** скачайте файл `jim-game.html` (в корне репозитория) и откройте его двойным щелчком в браузере — всё (картинки, шрифты) уже внутри, интернет не нужен.

Пересобрать этот файл после изменений: `python3 game/build_standalone.py`.

Или через локальный сервер:

```bash
cd game
python3 serve.py        # или: python3 -m http.server 8080
# открыть http://localhost:8080
```

## Управление

| Действие | Клавиши |
|---|---|
| Бег | ← → / A D |
| Прыжок | ↑ / W / Пробел (держать в падении — «голова-вертолёт», планирование) |
| Плазменный бластер | X / J |
| Удар головой-хлыстом | Z / K |
| Пауза / звук | P или Esc / M |

На телефоне появляются сенсорные кнопки.

## Что есть в игре
- Уровень ~9000 px с парящими и движущимися платформами, пропастями
- Вороны-враги (патруль и пикирование), атомы-патроны, сердечки-здоровье
- Таблички **GROOVY** — чекпоинты
- Коровы: коснись — «КОРОВА ЗАПУЩЕНА!» (+500)
- Босс Пси-Ворона с яйцами-бомбами и яростью на половине здоровья
- Финальный экран спасения принцессы

## Структура
- `game/index.html`, `game/style.css`, `game/game.js` — игра
- `game/assets/` — готовые спрайты (прозрачный фон) и фон
- `art/src/` — исходные сгенерированные картинки (на зелёном фоне), `art/chroma.py` — скрипт вырезания фона
