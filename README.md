# Червяк Джим — Космическое спасение (2D)

2D-платформер в стиле аниме/мультфильма на чистом HTML5 Canvas + JavaScript (без зависимостей).
Джим в космическом скафандре прорывается через астероиды, воюет с космическими воронами,
запускает коров, гоняет на космическом скутере и побеждает 10 боссов, чтобы спасти Принцессу Как-Её-Там.

## Запуск

**Играть онлайн:** https://erlan56region.github.io/CoffeeIT1/

**Самый простой способ:** скачайте файл `jim-game.html` (в корне репозитория) и откройте его двойным щелчком в браузере — всё (картинки, шрифты) уже внутри, интернет не нужен.

Пересобрать этот файл после изменений: `python3 game/build_standalone.py`.

Или через локальный сервер:

```bash
cd game
python3 serve.py        # или: python3 -m http.server 8080
# открыть http://localhost:8080
```

## Управление

| Действие | Клавиши |
|---|---|
| Бег | ← → / A D |
| Прыжок | ↑ / W / Пробел (держать в падении — «голова-вертолёт», планирование) |
| Джетпак | ещё раз нажать прыжок в воздухе и держать — тяга вверх; топливо (индикатор на баке) заправляется на земле |
| Присесть / ползти | ↓ / S (↓ + прыжок — спрыгнуть с платформы) |
| Стрелять | X / J (лазер стреляет очередью, пока держишь) |
| Удар головой-хлыстом | Z / K |
| Сменить оружие | Q / E / Tab или 1–5 |
| Пауза / звук | P или Esc / M |

На телефоне появляются сенсорные кнопки (◀ ▼ ▶, ОРУЖИЕ, ХЛЫСТ, ОГОНЬ, прыжок, пауза).

## Что есть в игре
- **11 локаций, 33 уровня** — у каждой свой фон, тайлы, враги и ловушки:
  пояс астероидов, свалка Нью-Джанк, ледяная планета, вулкан, подводный город,
  **космические гонки на скутере**, брюхо космического кита, фабрика роботов,
  кристальные пещеры, дворец Королевы Слизней, тёмная туманность (видно только вокруг Джима).
- **Карта мира** — пройденные уровни можно переигрывать, прогресс сохраняется в браузере.
- **10 боссов** (Пси-Ворона, Король Свалки, Йети, Лавовый Голем, Удильщик, Королева Паразитов,
  Мега-Робот, Кристальный Паук, Королева Слизней и финальный — Профессор Мозгокрут), у каждого 2 фазы.
- **Головоломки:** ключи и замки, рычаги (выстрелом, хлыстом или взрывом), кнопки и ящики,
  телепорты, мигающие и рассыпающиеся блоки, лазерные барьеры, тайные стены, низкие туннели (ползком).
- **Ловушки:** шипы, лава/кислота, гейзеры, сосульки, прессы, пружины, конвейеры, лёд, подводный кислород.
- **5 видов оружия:** бластер, дробовик, лазер (прошивает насквозь), ракеты (ломают стены), заморозка
  (замороженный враг становится платформой). Новое оружие дарят друзья.
- **32 вида врагов и 11 друзей** (летающая корова, Питер-щенок, механик, принцесса и др.) с подсказками.
- **Космические гонки** (уровни 16–18): космический скутер с пропеллером, 3 соперника,
  ускоряющие кольца, мины и лазерные ворота — нужно прийти первым.
- **Джетпак** за спиной Джима — точное управление в полёте.
- Жизни показаны лицами Джима, чекпоинты — флажки.

## Анимация
Персонажи анимируются «скелетно» (cut-out): спрайты порезаны на части (голова, торс, руки, бёдра, голени, крылья…),
каждая часть вращается вокруг своего сустава.
- **Джим:** дыхание в покое, цикл бега (шаги, сгиб коленей, мах руками, наклон корпуса, пыль из-под ботинок),
  торможение-занос, разворот, толчок/прыжок/падение с размахиванием руками, приседание при приземлении,
  голова-вертолёт, отдача бластера со вспышкой, голова-хлыст на длинной шее, отброс при уроне, смерть с кувырком.
- **Вороны:** взмахи крыльев, пикирование со сложенными крыльями, падение кувырком с перьями.
- **Принцесса:** машет рукой, юбка колышется волной, подпрыгивает.
- **Ощущения:** хит-стоп при ударе, камера с упреждением, тень под Джимом.

Части режет `art/rig.py` (→ `game/assets/rig/`). Позы — функции `pose*()` в `game/js/jim.js`.

## Структура
- `game/index.html`, `game/style.css` — страница игры
- `game/js/` — код: `core.js` (физика, ввод, звук), `jim.js` (скелетная анимация), `data.js` (оружие, локации,
  куски уровней и генерация 33 уровней), `world.js` (логика мира, враги, боссы), `draw.js` (отрисовка),
  `race.js` (гонки), `main.js` (экраны, карта, игровой цикл)
- `game/assets/` — спрайты (прозрачный фон), `assets/bg/` — фоны локаций
- `art/src/` — исходные сгенерированные картинки (на зелёном фоне), `art/chroma.py` — скрипт вырезания фона
